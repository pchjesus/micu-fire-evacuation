## 환경과 범위

PC는 macOS Aside의 Chromium 152이며 화면 크기는 1440×900 CSS 픽셀입니다. 테스트 주소 `127.0.0.1:8075`와 `localhost:8075`를 사용해 기존 운영 주소의 저장공간과 분리했습니다. 두 주소는 서로 다른 브라우저 저장공간입니다. Windows Google Chrome은 검사하지 않았습니다.

자동검사는 Node 26.7.0과 fake-indexeddb를 사용했습니다. fake-indexeddb는 메모리에서 IndexedDB 동작을 재현하는 테스트 도구입니다. 실제 브라우저·실제 기기 검사는 별도로 구분합니다. 이번 결과에 이전 버전의 수동 검사 건수를 합산하지 않았습니다.

## 제공 Excel 비교

원본은 읽기만 했고 앱 배포물에 포함하지 않았습니다. 파일에 연도는 없어 2026년을 명시해 비교했습니다.

| 파일 | 인원 | 날짜 열 | 이전 버전과 같은 배치 | 누락 날짜 |
| --- | ---: | ---: | ---: | --- |
| 9월.xlsx | 20 | 30 | 90개 날짜·듀티 | 없음 |
| 10월.xlsx | 20 | 30 | 90개 날짜·듀티 | 31일 |

두 파일의 SHA-256은 모두 `6331236c172f8b251c633ef17ca07b148055de26316c4787c2d58f5c8a3b7b5b`입니다. 파일 내용이 동일함을 확인했습니다. 날짜는 2행, 이름은 A열로 해석됐습니다. 선임 그룹 8명/6명/나머지는 기존 가정으로 표시됩니다. 공식 근무표 인증 검사가 아닙니다.

배포에 포함한 `scripts/verify-private-rosters.cjs`로 로컬에서 재검사할 수 있습니다. 파일 경로는 사용자가 지정하며 원본 이름·셀 값은 결과에 출력하지 않습니다.

```sh
node scripts/verify-private-rosters.cjs 2026 9 /path/to/9월.xlsx 2026 10 /path/to/10월.xlsx
```

## 모바일에서 확인한 범위

| 환경 | 확인 결과 | 남은 범위 |
| --- | --- | --- |
| Android 16 / Medium Phone API 36.1 / Chrome 에뮬레이터 | 초기 화면, 터치·스크롤, 수동 표시 이름 변경·저장 후 편집 종료·수정됨 표시 | 재시작 안정성·전체 파일 백업/복원 |
| iPhone 17 Pro / iOS 26.4 시뮬레이터 / Safari | 기본 샘플 화면의 초기 표시 | agent 미설치로 추가 조작·저장·파일 검사 미수행 |
| 실제 Android 휴대폰·iPhone | 연결된 기기 없음 | 전 항목 |
| Windows Google Chrome | 실행 환경 없음 | 전 항목 |

Android에서 모바일 자동화의 요소 목록 호출이 ADB 타임아웃으로 실패했습니다. 이후 스크린샷·좌표 터치로 편집·저장은 확인했습니다. 키 입력 도구에 보낸 문자열과 화면 입력이 일치하지 않아 실제 관찰값 `MOBILE-` 기준으로 저장 상태만 확인했습니다. 입력 도구와 IME의 영향은 구분하지 못했으며 전체 입력 호환성 합격으로 처리하지 않습니다.

Chrome 프로세스를 종료하고 같은 URL을 다시 연 뒤 빈 화면과 응답 없음이 관찰됐습니다. 21:28:17 로그에 `ANR in com.android.chrome`, `FocusEvent(hasFocus=true)` 입력 대기 5023ms가 있습니다. 재접속을 다시 시도해도 이 검사에서 저장값의 재시작 복원을 확인하지 못했습니다. 이 사실만으로 웹앱의 IndexedDB 결함 또는 에뮬레이터 단독 결함이라고 단정하지 않습니다.

실제 기기 검사 절차는 `docs/MOBILE_ACCEPTANCE_v0.7.3.md`에 있습니다. 단순 화면 표시를 저장·복원 완료로 보고하지 않습니다.

## 자료와 공개 범위

화면 증거에는 가상 샘플과 테스트 인원만 사용했습니다. 실제 운영 Excel, 개인 브라우저 DB, 전체 백업 JSON, 테스트 중 내려받은 이력 XLSX는 앱 ZIP에 포함하지 않습니다. ZIP은 허용된 실행 파일·문서·가상 fixture·검사 스크립트·화면 증거만 담고 개별 SHA-256과 압축 무결성을 검사합니다.

이전 배포본은 별도의 개발·백업 위치에서 보존했습니다. 현재 ZIP에는 이전 버전 ZIP을 포함하지 않습니다. DB v4는 같은 사이트에서 v0.7.2 이하로 파일만 되돌리는 다운그레이드를 지원하지 않습니다. 외부 서비스 게시나 GitHub Pages 배포는 수행하지 않았습니다.
