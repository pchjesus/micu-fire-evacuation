# 실제 기기 확인표 — v0.7.3 RC

실제 기기 결과가 기록되기 전에는 RC를 유지합니다. 화면 크기 검사·에뮬레이터 검사는 실제 기기의 파일 선택·저장소 정리·프로세스 재시작을 대신하지 않습니다.

2026-09-24 기준 실제 Android/iPhone은 연결되어 있지 않았습니다. Android 16 에뮬레이터 Chrome은 편집·저장은 확인했지만 재시작 후 ANR가 발생했습니다. iPhone 17 Pro / iOS 26.4 시뮬레이터는 초기 화면만 확인했습니다. 자동화 agent가 설치되어 있지 않아 추가 UI 조작은 미수행입니다.

비공개 모드는 일반 모드의 영구 보관 합격을 대신하지 않습니다. 저장소 부족·재읽기 실패는 자동검사에서 오류를 주입해 확인했으며, 실제 기기에서는 발생한 경우에만 성공 문구와 데이터 상태를 대조합니다. 검사를 위해 실제 기기 전체 저장공간을 가득 채우지는 않습니다.

한 항목이라도 실패하면 FINAL로 바꾸지 않습니다. Android 재시작 ANR는 단순히 대기 후 다시 열렸다는 이유만으로 합격 처리하지 않습니다. 같은 환경에서 재현 조건과 재발 여부를 확인하고 실제 기기에서도 검사합니다.
